# javacasestudy-zoomanagement
A zoo animal behavior simulation built with object-oriented programming (OOP) principles.

A zoo requires an animal behavior simulation system. There is an abstract class Animal with the methods makeSound() and eat(). The interfaces Mammal, Reptile, and Bird define specific behaviors such as nurse() or layEggs().

The Enclosure class manages a list of animals using aggregation, while the ZooKeeper class is responsible for feeding specific animals based on a schedule. FeedingSchedule serves as a distinct association class.
